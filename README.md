## Загрузка на Vercel

### Шаг 1: Создание нового репозитория
1. Создайте новый репозиторий на GitHub.
2. Склонируйте репозиторий на свой компьютер.
3. Перейдите в каталог проекта и выполните следующие команды:
    ```bash
    git init
    git add .
    git commit -m "Initial commit"
    git branch -M main
    git remote add origin <URL-адрес репозитория>
    git push -u origin main
    ```
4. Перейдите на GitHub и обновите страницу. Вы увидите, что ваш репозиторий теперь содержит все файлы проекта.
5. Скопируйте URL-адрес вашего репозитория.
6. Перейдите на [Vercel](https://vercel.com/) и войдите в свою учетную запись.
7. Нажмите на кнопку "New Project" и выберите "Import Git Repository".
8. Вставьте URL-адрес вашего репозитория и нажмите "Continue".
9. Выберите "Personal Account" и нажмите "Continue".
10. Нажмите "Deploy" и дождитесь завершения процесса загрузки.
11. Поздравляем! Ваш проект теперь загружен на Vercel.
12. Перейдите по URL-адресу, предоставленному Vercel, чтобы увидеть ваш проект в действии.


### Шаг 2: Обновление проекта
1. После загрузки проекта (server) на Vercel.
2. Внесите необходимые изменения в проект. [Изменить private URL](src/app/services/contact.service.ts) на тот котрый выдасть Vercel для server
